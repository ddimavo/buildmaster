# Заглушки API zAuctionHouse

Подмножество интерфейсов из `API/` репозитория https://github.com/GroupeZ-dev/zAuctionHouse (лицензия MIT, GroupeZ,
текст в `LICENSE-zAuctionHouse.txt`). Сигнатуры сверены с коммитом `04b7e600ae76c11136374893ff659f4fb61ba4e5`.

Зачем: настоящий API тянет за собой Sarah, FoliaLib, zMenu и т.д. из репозиториев, недоступных при сборке, а нужна лишь малая часть.
Заглушки используются только для компиляции и тестов и **в jar не попадают**: во время работы классы берутся из установленного
zAuctionHouse. Поэтому здесь объявлено ровно то, что вызывает IndustryReborn; при обновлении zAuctionHouse сигнатуры нужно сверять.
