# Скриншоты меню для релизов

Меню рисуются из **настоящего содержимого инвентарей плагина** (не вручную): тест-выгрузка собирает названия, описания и значки каждого меню в JSON, `render.py` рисует окно сундука
в HTML, `shot.js` (Playwright) делает снимки. Значки схематичные (цвет и подпись материала), текст и раскладка - как в игре.

1. Скопируйте `ScreenshotDump.java.txt` в `src/test/java/ru/industryreborn/ScreenshotDump.java` (убрав `.txt`), поправьте сценарии под новые меню и выполните
   `gradle test --tests '*ScreenshotDump'` - файл `/tmp/claude-0/proto/release/real.json` создаётся тестом. Удалите тест после выгрузки (в коммиты он не входит).
2. В каталоге с `real.json`: `python3 render.py` (список подсвеченных ячеек - словарь `HL` в начале), затем `NODE_PATH=$(npm root -g) node shot.js <имена сценариев>`.
3. Снимки кладутся в `docs/screenshots/<версия>/`, в раздел версии в `CHANGELOG.md` добавляется блок «Как выглядят меню» со ссылками вида
   `https://github.com/<владелец>/<репозиторий>/blob/<коммит>/docs/screenshots/<версия>/<файл>.png?raw=true` (коммит - тот, в котором лежат снимки).
