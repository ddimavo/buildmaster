# Участки игроков (WorldGuard)

Игрок может продавать и сдавать в аренду **свой регион WorldGuard** через плагин. WorldGuard - необязательная зависимость
(`softdepend`); связь с ним идёт через рефлексию, поэтому сборка от версии WorldGuard не зависит.

## Порядок

1. `/district region bind <регион> <house|warehouse|hotel>` - стоя в мире региона. Игрок должен быть его владельцем.
2. Администратор одобряет заявку (`/district moderation`). До одобрения участок виден только владельцу.
3. Совладельцы региона выполняют `/district region consent <участок>`.
4. `/district region sale <участок> <цена|off>`, `/district region rent <участок> <цена за сутки|off>`.
   Цена аренды не выше предела по размеру (`player-plots.*` в config.yml).
5. `/district region access <участок> none|shared` - сохраняет ли арендодатель доступ на время аренды
   (только для участков не меньше `shared-access-min-volume`).
6. `/district region unbind <участок>` - отвязать свободный участок. Права в WorldGuard не меняются.

## Что происходит с регионом

| Событие | Владельцы региона | Участники |
|---|---|---|
| привязка | без изменений | без изменений |
| аренда | арендатор | арендодатель (если `shared`) |
| конец аренды, выселение | арендодатель и совладельцы | участники, что были при привязке |
| продажа | покупатель | пусто |

Если WorldGuard не принял изменение, аренда и покупка отменяются без списания денег.

## Защита вещей арендодателя

- Арендатор ломает только блоки, которые поставил сам (`player-plots.tenant-break-own-only`).
- Контейнеры: без записи в книге учёта - контейнер арендодателя, с записью - поставившего. Чужие не открываются.
- Постройки арендодателя в книгу арендатора не попадают.
- Конец аренды: убираются блоки и контейнеры арендатора, предметы идут в его хранилище. Здание, контейнеры и вещи
  арендодателя не трогаются, сущности не трогаются. Полный сброс к исходному виду для участка игрока не применяется.
- Здание участка игрока менять командой «замена материала» нельзя.

## Деньги

Аренда: арендодателю на кошелёк за вычетом налога на аренду (`bank.rent-tax-percent`, налог - в казну). Продажа: продавцу
полностью. Налог на имущество с участков игроков не берётся.

## Ограничения

- Интеграция с WorldGuard проверена только на подменённом API в тестах (`PlayerPlotsTest`): проверьте на тестовом сервере.
- Поддерживаются только прямоугольные регионы.
