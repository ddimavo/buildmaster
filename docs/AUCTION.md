# Общий аукцион (zAuctionHouse)

Нужен плагин [zAuctionHouse](https://github.com/GroupeZ-dev/zAuctionHouse) (необязательная зависимость).

## Что происходит

1. Игрок не забрал вещи из хранилища за `storage-days` суток (по умолчанию 60) **или** администратор принял решение по арестованным
   вещам: `/district arrest auction <игрок>`. Вещи получают состояние «аукцион».
2. Раз в ~20 секунд (вместе с проверкой аренды) IndustryReborn выставляет ожидающие вещи на аукцион от имени продавца **«Казна»**
   (`auction.seller-name`): не больше `per-run` за запуск и `max-listings` одновременно.
3. Покупатель платит как обычно. Деньги, которые аукцион отправил бы продавцу, зачисляются **в казну IndustryReborn** (налог аукциона,
   если он настроен в zAuctionHouse, вычитается по его правилам).

## Цена

`цена за предмет (auction.prices.<МАТЕРИАЛ> или default-price) × количество × price-multiplier`, не меньше `min-lot-price`,
затем приводится к пределам цен экономики zAuctionHouse. Каждый стак - отдельный лот.

## Безопасность вещей

Предмет сначала убирается из хранилища и только потом выставляется. Если выставить не удалось (ошибка базы и т.п.), он возвращается
в очередь. Если сервер упадёт в момент между этими шагами, предмет может пропасть, но не продублируется.

## Как устроена связь

- `src/zahStub` - подмножество интерфейсов API zAuctionHouse (MIT, сверено с коммитом `04b7e600`), нужное только для компиляции
  и тестов. В jar оно не попадает: на сервере используются классы установленного zAuctionHouse.
- IndustryReborn регистрирует в zAuctionHouse экономику `industryreborn_treasury`. Она делегирует всё настоящей экономике (валюта,
  формат, пределы, списание у покупателей), кроме счёта продавца «Казна»: он отображается как баланс казны, а зачисление идёт в казну.
- Лоты хранят имя этой экономики, поэтому после перезапуска она должна быть зарегистрирована **до** чтения лотов из базы. Для этого
  в plugin.yml указано `loadbefore: [zAuctionHouse]`. Если порядок загрузки изменён другим плагином, лоты казны будут недоступны
  до исправления (zAuctionHouse напишет в лог, что не нашёл экономику `industryreborn_treasury`).
- `auction.economy` - имя экономики zAuctionHouse, чью валюту использует казна (пусто - экономика по умолчанию).

## Ограничения

- Только один сервер без кластера (Redis): в кластере выплаты откладываются, а казна их не заберёт. В этом случае
  `/district auction status` покажет «недоступен», вещи останутся в очереди.
- Интеграция проверена только на подменённом API (тесты). Проверьте на тестовом сервере: покупка лота казны и увеличение
  казны (`/district auction status`).
- Если zAuctionHouse не установлен или недоступен, просроченные вещи удаляются, как и раньше.
