# Отели

**Отель** - участок типа `hotel`: администратор создаёт его обычной командой `/district create <номер> hotel <цена|-> <аренда|->`,
игрок покупает или арендует его и становится управляющим (как у любого предприятия). **Номера** - вложенные в отель участки
типа `room`, их создаёт администратор.

## Устройство

* Номер - настоящий участок: у него своя область (интерьер), аренда, права, книга учёта блоков, снимок для сброса, хранилище вещей гостя.
  Поэтому работают все правила обычных участков: аренда до 14 суток, продление не выше 14, автопродление, отсрочка платежа 3 суток, антидюп.
* Стены, пол, потолок и коридоры принадлежат **отелю**, а не номеру: гость не может их менять.
  По координатам выбирается самый внутренний участок.
* Номера только арендуются (покупка запрещена); при выезде номер всегда сбрасывается к исходному виду.

## Деление отеля

| Способ | Команда |
|---|---|
| По двери | встаньте в коридоре, смотрите на дверь, `/district room auto <номер> <цена>`, затем `room confirm` / `room cancel` (область подсвечивается частицами) |
| Вручную | выделите интерьер (`/district wand`), `/district room create <отель> <номер> <цена>` |
| Шаблоном | выделите интерьер первого номера, `/district room template <отель> <префикс> <x\|z> <шаг> <количество> <цена> [dx dy dz]` |
| Дверь | смотрите на блок двери, `/district room door <номер>`; `room door clear <номер>` убирает двери |
| Цена | `/district room rate <номер> <цена>` (администратор - любая; управляющий - до `maxrate`) |
| Предел цены | `/district room maxrate <отель> <цена>` |
| Удаление | `/district room delete <номер>` (только свободный); отель с номерами удалить нельзя |

Шаблон: первый номер - выделение, остальные сдвинуты на `шаг` блоков вдоль оси; номера называются `префикс1`, `префикс2`...
Дверь задаётся смещением от угла каждого номера. Все области проверяются до создания: если какая-то выходит за отель или
пересекается, не создаётся ничего.

## Двери

Над каждой дверью со стороны коридора висит голограмма: номер, статус, гость и срок (`holograms.doors`).

Дверь номера запирается для посторонних: занятый номер открывают гость, его доверенные, управляющий отеля и администратор.
Свободный номер открыт всем (чтобы осмотреть). Учитывается и верхняя половина двери.

## Деньги

```
гость платит за номер
        |
        +-- у отеля есть управляющий --> налог на аренду (bank.rent-tax-percent) в казну,
        |                                остальное на счёт отеля (его можно снять через банк)
        |
        +-- управляющего нет ----------> всё в казну
```

Это относится к первой оплате, продлению и автопродлению.

## Выезд и гости

* При выезде (по желанию гостя или по окончании аренды) вещи возвращаются в хранилище **тому, кто их поставил** (книга учёта),
  содержимое исходных контейнеров идёт гостю, номер сбрасывается к исходному виду.
* Пока в отеле есть гости: полный сброс здания администратором запрещён; при отказе управляющего здание целиком не сбрасывается
  (режим «только вещи»), и вещи гостей в номерах не затрагиваются. Если управляющий ушёл, номера остаются в аренде,
  а оплата идёт в казну.
* Антидюп: исходная мебель номера при поломке ничего не даёт (она вернётся при сбросе).

## Ограничения

* Отели создают только администраторы: отели игроков с проверкой появятся вместе с участками игроков на WorldGuard.
* Выселять гостя может только администратор.
* Работники отеля с процентом от аренды пока не реализованы.
