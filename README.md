# BuildMaster - район коммерции для Paper

Плагин делит район на участки со зданиями. Игрок покупает или арендует участок и
видоизменяет здание через меню или команды.

* Paper 1.21.6 - 26.x, Java 21+
* Нужен **Vault** и любой экономический плагин (например EssentialsX)

## Сборка

```bash
gradle build
```

Готовый файл: `build/libs/BuildMaster-1.0.0.jar` -> в папку `plugins/`.

## Как это работает

* Админ выделяет здание (`/district wand`), создаёт участок `/district create <номер> <цена|-> <аренда/сутки|->`.
  Исходный вид здания сохраняется в `plugins/BuildMaster/snapshots`.
* Админ может разметить **зоны** (фасад, крыша, интерьер): выделить область внутри участка и
  `/district zone add <номер> <имя> [блок-иконка]`.
* Игрок: `/district` - меню; покупка, аренда в сутках, продление, автопродление.
* Замена материалов: меню "Изменить здание" или `/district replace <зона|все> <из> <в>`.
  Ориентация блоков (ступени, плиты, двери) сохраняется. Запрещённые блоки - в `config.yml` (`replace-banned`).
* Отказ от участка или окончание аренды: все предметы из контейнеров, рамок, выброшенные предметы и блоки,
  поставленные игроком, возвращаются владельцу (или ждут его в `/district claim`),
  здание возвращается к исходному виду.
* Защита: на участке строят только владелец и доверенные (`/district trust`). Посетители могут
  пользоваться дверями, кнопками, рычагами, табличками.

## Права

| Право | По умолчанию | Описание |
|---|---|---|
| `buildmaster.use` | все | игровые команды |
| `buildmaster.admin` | op | создание и настройка участков |
| `buildmaster.bypass` | op | обход защиты участков |

## Ограничения

* Блоки с данными (таблички, баннеры, головы, кровати) при сбросе здания восстанавливаются без данных (текст табличек теряется).
* Содержимое контейнеров исходного здания не сохраняется: при сбросе контейнеры пустые.
* Вне участков плагин ничего не защищает (улицы - через WorldGuard).
