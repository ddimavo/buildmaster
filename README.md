# IndustryReborn - район коммерции для Paper

Плагин делит район на участки со зданиями. Игрок покупает или арендует участок и
видоизменяет здание через меню или команды.

* Paper 1.21.6 - 26.x, Java 21+
* Нужен **Vault** и любой экономический плагин (например EssentialsX)

## Сборка

```bash
gradle build
```

Готовый файл: `build/libs/IndustryReborn-<версия>.jar` -> в папку `plugins/`.

## Как это работает

* Админ выделяет здание (`/district wand`) и создаёт участок:
  `/district create <номер> <тип> <цена|-> <аренда в сутки|->`. Типы: `house`, `shop`, `workshop`, `restaurant`, `warehouse`.
  Позиция админа становится центром голограммы.
* Игрок покупает или арендует участок (меню `/district`) и становится *управляющим*; главным владельцем остаётся администрация.
* Аренда до 14 суток, цена за сутки. Продлить можно так, чтобы остаток не превысил 14 суток. Есть автопродление.
* Не хватило денег на автопродление - отсрочка 3 суток, участок заморожен (строить нельзя, торговля табличками работает).
* Название и описание участка публикуются после одобрения администратором (меню `/district moderation`).
* Вещи возвращаются в **хранилище** (`/district storage`) каждому владельцу: печь - тому, кто её поставил,
  сундук с содержимым - тому, кто поставил сундук. Хранятся 60 суток.
* **Права:** управляющий выдаёт другим игрокам по отдельности строительство, контейнеры и станки
  (`/district perm`), может открыть станки или контейнеры для всех (если разрешено для типа участка).
* **Мастерские платят за электричество** с денежного счёта участка (`/district account`); без него станки стоят.
  В магазине - по одному верстаку, печи и наковальне; остальные станки - только в мастерской.
* **Услуги мастерских:** клиенты заказывают переплавку, ремонт и другие услуги, оплата и материалы хранятся в эскроу,
  мастерская исполняет заказ сама при наличии электричества (`/district service`).
* **Интерфейс:** единое современное оформление меню, цветные разделы, панель игрока, информативные карточки.
* **Позиция голограммы:** игрок предлагает место, администратор одобряет (`/district hologram`).
* **Арестованные вещи:** меню администратора - вернуть, удалить или отдать на аукцион, причина обязательна.
* **Общий аукцион:** невостребованные вещи хранилищ продаются на zAuctionHouse от имени казны, выручка идёт в казну
  (`/district auction`, [docs/AUCTION.md](docs/AUCTION.md)).
* **Работники и зарплаты:** доска объявлений с вакансиями, отклики, зарплата за время на участке и процент от дохода
  (`/district job`, [docs/JOBS.md](docs/JOBS.md)).
* **Участки игроков:** привязка региона WorldGuard, одобрение, согласие совладельцев, предел цены аренды, продажа и аренда
  с возвратом региона (`/district region`, [docs/PLAYER_PLOTS.md](docs/PLAYER_PLOTS.md)).
* **Отели:** номера - вложенные участки со своей дверью и защитой, гости снимают их сами, оплата идёт управляющему отеля
  за вычетом налога на аренду (`/district room`, [docs/HOTELS.md](docs/HOTELS.md)).
* **Производство и улучшения:** автоматические линии переработки сырья и платные уровни мастерской (`/district factory`).
* **Банк и электростанции** - административные здания: комиссии, налоги, штраф и проверка счетов; электросеть с мощностью станций,
  отключениями и отчётами по районам. Подробно: [docs/BANK_GRID.md](docs/BANK_GRID.md).
* Администратор может выселить, изъять (арест вещей) и сбросить здание в любой момент - всегда с причиной,
  которая попадает в журнал игрока (`/district journal`).

**Полное руководство:** [docs/MANUAL.md](docs/MANUAL.md) (красивая HTML-версия: [docs/manual.html](docs/manual.html),
собирается командой `python3 scripts/build-manual.py`).

Подробности и план работ: [docs/DESIGN.md](docs/DESIGN.md).

## Права

| Право | По умолчанию | Описание |
|---|---|---|
| `industryreborn.use` | все | игровые команды |
| `industryreborn.admin` | op | создание и настройка участков |
| `industryreborn.bypass` | op | обход защиты участков |
| `industryreborn.bank` | op | банк: казна, все счета, комиссии, налоги |
| `industryreborn.grid` | op | электросеть: станции, тарифы, отключения, районы |

## Тесты и релизы

```bash
gradle test      # JUnit + MockBukkit
gradle build     # сборка jar
```

* Каждый push и pull request собирается и тестируется (`.github/workflows/build.yml`).
* **Автоматический выпуск:** каждый коммит в `main` и `claude/**` собирается и публикуется: если релиза текущей версии из
  `build.gradle` ещё нет, выходит обычный релиз, иначе пререлиз `<версия>-dev.<N>` (хранятся последние 10).
  Пропустить выпуск: `[skip release]` в сообщении коммита.
* Чтобы выпустить релиз вручную, создайте тег: `git tag v1.1.0 && git push origin v1.1.0`. Action соберёт плагин,
  прогонит тесты и опубликует `IndustryReborn-<версия>.jar` с контрольной суммой в GitHub Releases.
  Описание релиза берётся из раздела `## [версия]` файла `CHANGELOG.md`. Теги с дефисом (`v1.2.0-beta.1`) выходят как пререлиз.

## Ограничения

* Исходные контейнеры здания после сброса пустые (иначе можно забрать их содержимое дважды).
* Вне участков плагин ничего не защищает (улицы - через WorldGuard).
* Плагин пока не проверялся на живом сервере: см. [docs/DESIGN.md](docs/DESIGN.md).
